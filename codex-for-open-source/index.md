# OpenAI 送了我半年 ChatGPT Pro，理由是我在维护开源


今天邮箱里跳出来一封信，标题是："You can just build things, enjoy 6 months on us"。

发件人是 OpenAI 的 Codex 团队。点开第一行就是大写的 "You're in."，然后跟着一句："Thanks for maintaining open source projects."

我盯着那行字看了三遍，没忍住笑出声。

{{< image src="/pictures/posts/codex-open-source-email.png" caption="白嫖成功" width="800" class="center" >}}

前阵子顺手填了他们的 Codex for Open Source 申请。当时没抱什么希望，就把给 context-mode 提的几个 PR，还有自己的 byf 和 dev-skills 填了上去。

算了一下，ChatGPT Pro 一个月 200 刀，半年就是 1200 刀。说实话，省下这笔钱是真爽，但我最高兴的反倒是邮件里那句："reviewing changes, maintaining releases, keeping quality high"。

做开源最烦的从来不是写代码，而是大半夜看陌生人格式稀烂的 PR、排查复现不了的 issue、还有发版前反复测那一堆琐碎的边界情况。这些破事既不能录成炫酷的 demo 视频，也没法发推特装逼。平时能收到的最高待遇，无非也就是 issue 底下一个 emoji 反应或者一句干瘪的 "thx"。

结果今天被人用白纸黑字的邮件正式夸了一句"谢谢你维护开源"，还直接塞了半年 Pro 额度。

虽然是个 noreply 邮箱回不了信，但心情确实大好。接下来半年 Codex 可以敞开造了，继续改 issue 去。
