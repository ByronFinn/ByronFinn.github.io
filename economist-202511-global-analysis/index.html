《经济学人》2025年11月刊展现了一幅全球秩序深度分化的图景：一边是中美围绕半导体与技术栈的长期消耗战，另一边是各国在疲弱内需与资产负债表衰退边缘的防御性收缩。

政治与外交：离婚不离家的科技拉锯
#

  • 文中详细提到中美关系在贸易和科技领域的博弈持续升级，美国出台新一轮芯片管制措施，但中国通过产业链韧性与国内替代应对。

  • 中国与中东、非洲国家合作深化，尤其在能源与基建领域签署多项战略协议。

  • 国内治理层面，文件强调了“稳增长、促民生、强科技”的政策三支柱。

中美“脱钩”像离婚不离家，嘴上喊分手，心里还惦记着芯片。

经济与金融：资产负债表与内需收缩
#

  • GDP 增速稳中略降，内需恢复乏力，居民消费更趋防御性。
  • 房地产市场继续筑底，政策层面加大保障性住房投放力度。
  • 人民币汇率波动加大，央行干预频次上升，核心诉求在于稳汇率与防范资本外流。
  • 股市在流动性托底政策下略有反弹，但风险溢价与资金面依然紧绷。

政策托市犹如温水调理，见效慢、苦味重，但在杠杆去化期已无更烈猛药。

科技与产业：国产替代与出海围堵
#

  • 半导体、人工智能与新能源依然是国家资本配置的核心主线。
  • 国内大模型进入工程落地与商业化变现的洗牌阶段，腰部创业团队加速退场。
  • 新能源汽车出口规模攀升，但直面欧洲反补贴关税与地缘合规高墙。
  • 国产算力芯片良率与全栈软件适配进入攻坚区。

社会与民生：普遍的不确定性与超额储蓄
#

  • 青年失业与结构性错配依然严峻，岗位需求与高校产出脱节。
  • 居民储蓄意愿高企，即期消费压缩，折射出对未来预期的深度保守。
  • 养老与医疗保障体系在老龄化加速背景下面临长周期收支张力。

国际格局：断裂带上的中间缓冲地带
#

  • 俄乌冲突陷入长周期僵持，欧洲能源重构付出长期成本。
  • 中东地缘局势不确定性推高避险溢价，国际油价宽幅震荡。
  • 东南亚成为中美供应链重构的核心离岸转运中继，但双边选边压力持续积聚。

研判与结语
#

报告将 2026 年定调为“内需修复与科技决胜之年”。然而现实从不因愿景而改变其物理规律——全球流动性收紧与地缘裂痕的修复注定漫长，个体与企业的唯一解法是收拢杠杆，直面真实的周期风暴。
